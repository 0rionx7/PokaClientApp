# Poka & Chinese Poker

A React-based frontend for a real-time multiplayer card game featuring **Poka** (Greek poker variations) and **Chinese Poker**.

This repository contains the client-side application only. Backend services and server-side game logic are maintained separately and are not included in this repository.

## Overview

The application provides an interactive interface for multiplayer card games, with real-time communication between players through Socket.IO.

### Features

- Multiplayer card game interface
- Support for Poka and Chinese Poker
- Real-time communication using Socket.IO
- State management with Redux Toolkit
- Drag-and-drop interactions
- Animated UI transitions
- Responsive and interactive user experience
- Application monitoring with Microsoft Application Insights

## Tech Stack

### Frontend

- **React 19** – UI development
- **Vite 7** – Development server and build tool
- **React Router 7** – Client-side routing
- **Redux Toolkit** – Application state management
- **React Redux** – Redux integration
- **Sass** – Styling
- **Framer Motion** – Animations and transitions
- **React DnD** – Drag-and-drop interactions
- **Emoji Picker React** – Emoji selection

### Real-time Communication

- **Socket.IO Client** – Real-time communication with the game server

### Monitoring

- **Microsoft Application Insights** – Application monitoring and telemetry

### Development Tools

- **ESLint 9** – Code linting
- **Prettier 3** – Code formatting
- **React Compiler** – React optimization
